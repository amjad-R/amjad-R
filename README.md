**AI Evaluation Engineer · Full-Stack Developer · Agadir, Morocco**

AI evaluation engineer based in Agadir, Morocco, with five years of programming behind me. I build and review the tasks used to test how well AI coding agents actually work.

## AI evaluation work

I work as an AI Expert Contributor through HireArt, and I have also worked with Alignerr and other AI data platforms. Project and client names are left out here because the work is under NDA, so the projects below are described by what they were.

**Agent benchmark tasks**
Terminal and coding tasks for AI agents, each packaged in Docker with a reference solution, an automated test suite and a grading rubric. 170+ tasks authored across three benchmark editions, and 110+ existing tasks corrected in a dedicated fix pipeline.

**Code review of AI output**
Reviewing AI-written changes against real pull requests, rating each one on several quality axes and writing feedback for every rating. Also multi-turn sessions with coding agents, evaluated turn by turn. 320+ tasks.

**Math problem authoring**
Original university-level problems with complete worked solutions, written to test model reasoning. 110+ problems.

**Research replication and professional workflow tasks**
Tasks that ask a model to reproduce results from ML papers, and tasks modelled on real professional work, with rubrics for grading the output.

**Review and adjudication**
Promoted from contributor to reviewer on several of these projects, and to adjudicator on some, checking other contributors' work before delivery. Selected as a top performer on the code review project.

### Open-source projects I have worked with

The code review work was done on real repositories, including pandas, MLflow, Prefect, PyTorch Lightning, TensorFlow, SymPy, Requests, Flask, Dagster, Airbyte, OpenBB, Zipline, Netmiko, pymodbus and python-can.
